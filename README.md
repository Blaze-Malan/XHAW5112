# NLG EA Gaming App

## 1. Introduction
The NLG EA Gaming Webpage is a website designed to help users explore gaming packages and book gaming experiences. The website provides information about available activities, package prices, and booking options in one convenient place.

The website is designed for friends, families, gamers, and teams who want to enjoy exciting gaming experiences together.

---

## 2. Project Objectives (Part 2)
The main objectives of this application are to:
* Display a home page with easy navigation.
* Provide information about gaming experiences.
* Show package prices and included services.
* Allow users to explore booking options.
* Provide contact information for enquiries.
* Create a simple and user-friendly experience.

---

## 3. Features

### Home Page
The home/index page introduces users to NLG EA Gaming and provides navigation to the main pages of the website.

### Services
Users can explore everything we offer as well as our available facilities:
* Gaming Sessions
* Esports training
* Tournaments
* Events and parties

### About 
Users can learn a little about NLG EA Gamings history and their mission as an establishment.

### Contact
The contact section provides information to help users contact NLG EA Gaming.

### Navigation
The website includes both top and bottom navigation bars to help users move between the different pages.

## 5. Website Design
The website uses a modern gaming-inspired design with a turquoise to yellow gradient header and colourful package sections.

The main colours include:
* Turquoise
* Orange
* Yellow
* Navy Blue
* Light Blue

The interface is designed to make information easy to read and navigation easy to understand.
