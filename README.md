# NLG EA Gaming Website

## 1. Introduction
The NLG EA Gaming Webpage is a website designed to help users explore gaming packages and book gaming experiences. The website provides information about available activities, package prices, and booking options in one convenient place.

The website is designed for friends, families, gamers, and teams who want to enjoy exciting gaming experiences together.

## 2. Project Objectives (Part 2)
The main objectives of this application are to:
* Display a home page with easy navigation.
* Provide information about gaming experiences.
* Show package prices and included services.
* Allow users to explore booking options.
* Provide contact information for enquiries.
* Create a simple and user-friendly experience.

### Project Objectives (Part 3)
The objectives for Part 3 are to:
* Add a table to present information clearly.
* Add a drop down menu for filtering game categories.
* Validate user input in the contact form and fees calculator.
* Use JavaScript to make the website more interactive with search, pop ups, and a booking calculator.
* Create additional pages for events, tournaments, locations, the community, and FAQs.
* Improve navigation with a shared hamburger menu.

## 4. Features

### Home Page
The home page introduces the arena, gaming packages, individual experiences, and upcoming events.

### Services
Explore gaming sessions, esports training, tournaments, events and parties, facilities, and a visitor-policy table.

### About
Learn about the arena's mission and what it offers players.

### Experiences and Fees
Explore VR, racing simulator, and escape room experiences. The fees calculator provides live estimates and booking count discounts for packages and experiences. Booking is a demo; no reservation or payment is processed.

### Events and Tournament
Browse upcoming events and the featured VALORANT tournament. The tournament page includes event details, a statistics table, and pop-ups for rules and team registration.

### Equipment and Game Library
View example gaming setup specifications and filter the game library by competitive, casual, or sports games. The filter requires JavaScript; all games remain visible when JavaScript is unavailable.

### Community and Locations
Discover community activities and the Discord link, and view the Johannesburg, Cape Town, and Durban location cards.

### FAQs
Search and filter questions by topic, then expand them to read answers about visiting the arena.

### Contact
Find contact details and use a demo contact form with required field and email validation. Messages are not sent or stored.

### Navigation
Use the shared hamburger menu to navigate between pages; some pages also include footer quick links.
